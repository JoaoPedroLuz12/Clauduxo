# Clauduxo
Criando com Claude

## Tarefas

`index.html` é uma lista de tarefas pessoal: prazos, prioridades, filtros (pendentes, para hoje, concluídas) e tarefas agrupadas por prazo (atrasadas, hoje, amanhã, próximos 7 dias).

- **Versão na nuvem (recomendada):** publicada no claude.ai. As tarefas ficam salvas na sua conta e aparecem iguais no celular e no computador.
- **Versão deste repositório:** abra o `index.html` no navegador. As tarefas ficam salvas nesse navegador (continuam lá depois de fechar a aba), mas não passam para outros aparelhos.
